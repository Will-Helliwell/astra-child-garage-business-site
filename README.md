# Website Replica from figma design

A client had a Figma design for their garage sale business, and wanted this replicated exactly in WordPress.

Instead of using a drag-and-drop page-builder (e.g. Elementor or Divi), I used a child theme with custom-code which ensured:
- Exact replication, pixel-for-pixel - no trade-offs because the page-builder wasn't flexible enough
- Fast load times - with my clean code and without all the bloat from the page-builder, the website is super responsive, which is great for customer experience and Google rankings
